What is shared. tic-data.js is generated from the workbook, tic-series.js from re-running the KMV engine offline over the cached API captures, and tic-lib.js holds the canonical field inventory, the formatters for very small probabilities, and the six SVG chart builders. Each prototype iterates that inventory, so no skin can silently drop a column — and swapping the skin never touches the data layer.

Six plates per direction. Four the workbook supports directly — DD dumbbell, rating migration, PD on a log axis, asset versus equity — plus two the engine supplies: EM convergence, and the asset / equity / default-point paths across the 150-day window. Select AMZN to see the empty state: that cached capture returned no daily prices, so those two plates say so instead of faking a curve.

What is not decided yet. Interaction beyond selecting an issuer — live ticker entry, methodology knobs, the AI explanation call — is drawn but not wired, and the backend does not yet emit the two-snapshot shape the workbook uses. Both are follow-on work once a direction is chosen.
