## 思想综述

### 一句话

**信用评级不是违约概率，而是对"违约时间 τ 的分布"的编码。** 一个信用由两个行为因子刻画：
μ = E[τ]（还能活多久）与 CCM = E[τ]·E[1/τ] − 1（恶化聚集多重）；评级 TiC = CCM/μ^Q。
在 (ln μ, ln CCM) 平面上，同一评级等级历年数据连成斜率为 Q 的直线——**历史 PD 沿线剧烈滑动（这是市场周期），线本身几乎不动（这才是评级）**。"Cross-Time inconsistency 不是缺陷，是本该预期的行为"——这句话是整套理论的支点。

### 思想的四层

1. **问题层——两类不一致 + 无数据难题。** 同一字母的历史违约率年际差两个数量级（Moody's B：0.0%–9.8%）；跨体系换算不稳到银行宁可不换。更深的困境是"全世界就一个 IBM"：单一大公司没有违约频率可数，风险管理的根本难点是**没有数据**。KMV 从股价剥离信用信息解决了"有没有"，但剥出来的是短期（PIT）信息——"提前几天告诉我这个公司出问题，已经太晚了"。
2. **哲学层——用行为定义信用，不用意图。** "你给我写个数学公式去定义信用，每个人写出来的都不一样"——所以不定义本质，只看行为与后果（反洗钱类比：拆分存款这个行为就是洗钱，不问动机）。两个基本信用行为：恶化与违约；量化它们的 CCM 与 μ 来自"做了二三十年"的实践经验，**"主要是经验，不需要数据"**。这是论文 Behavior-Specific 分类学的口述源头：agency 的流程法、银行的回归法、学术的模型法，都是行为法的特例——这就是 "Universal" 的确切含义（口述版："就像 E=mc²，一个总公式，每种数据推导出一个算法"）。
3. **数学层——把"时间一致"做成不变量。** first-passage 模型里 τ 服从 Inverse Gaussian，CCM 与 μ 都依赖漂移 η_A——KMV 的 DD/EDF 因此天生不稳（课件 slide 96 五个词点破："η_A makes both unstable"）。**Q=1 是唯一让 η 约掉的选择：TiC = CCM/μ = σ_A²/ln²(A/D)**，于是评级在 Girsanov 变换下不变——风险中性与实证测度给出同一个字母，"去掉股票的行为，剩下信用的行为，就稳定了"。
4. **制度层——评级与监管要求打通。** 资本=置信水平 α，而 α 只由 CCM 决定（与 μ 无关）；拨备随 μ 变。由此评级第一次与 Basel 资本/CECL 拨备有了显式公式连接，跨体系转换有了"无监管套利"判据：**换体系时 PD 与 α 都不许变**——解 CL_B(CCM*) = CL_A(CCM_A)，这正是引擎 `solve_ccm_star` 每天在做的事。

### 精神（他反复回到的几件事)

- **实践驱动的理论洁癖。** 给工行纽约做了一年、500 万美元的项目"马马虎虎能交差，可是我自己不觉得高兴——没有从理论上把问题解决"。方法的每一步都要"理论上说得通"，否则"你不是胡说八道嘛"。
- **数学是不可替代的内核。** 第一篇论文发美国数学会刊、至今每年发数学论文；"AI 是行业平均水平，新手做不过它，专家不靠它赚钱"；AI 不能创新理论（"没有过的东西，他没办法，他跟你胡编"），但应该把实现全部自动化。
- **精度纪律。** "金融里一点都不能随机……必须严格精确，固定死，彻底固定死"——核心函数做成标准化工具接口，AI 只许调用不许发挥；"每一个数字都可以追溯，换不同的大模型，结果必须稳定"。（本项目引擎+静态预计算+provenance appendix 的架构，就是这条纪律的工程形态。）
- **免费与传承。** 愿景说了两遍："查股价的时候，底下同时给一个短期评级一个长期评级，像股价一样免费"。PFPA 课程收入全捐、年会免费、义工授课；办银行是为了"华人第一家、传三代"。他把方法教出来，是希望"能够花时间读懂这个东西"的下一代接过去。
- **诚实面对未完成。** 论文页页有 DRAFT 水印；课件 PIT→TTC 一章只有标题；专著"上千页、200 页证明，不知道何年何月写得出来"。这套理论仍在生长——本地 30 页稿已被作者本人定性为旧版。

### 对本项目的直接意义

- **这个 dashboard 就是他愿景的实现**：ticker 进、字母出，短期（PIT PD/EDF）与长期（TTC 字母）并排，免费公开。
- **权威链**：数值正确性以**论文**为准（Table 8、CML=e^1.35、CCM*=1.35373/2.22928 锚点、eq 28 outlook）；课件是教学叙事但数字有坑（R_A 差 √250、slide 112 TiC 复现不出、同页双 σ_A——engine 均已修正或绕开，详见 `lecture-deck.md §6`）；75 页 deck 提供 τ≈1 的书面依据但有 365/250 分母不一致。
